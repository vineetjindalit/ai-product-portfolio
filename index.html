SAMSUNG · AUTOMATION

Android Sanity Automation

Python + ADB · System performance · Workflow automation
Problem
Engineers manually connected devices, ran ADB/grep commands, exercised apps, collected CPU/memory/performance/thermal parameters across Android versions, and populated comparison spreadsheets.
Approach
Proposed and built a Python/ADB workflow that automated device actions, parameter collection, cross-version comparison and multi-sheet Excel report generation with anomaly highlighting.
Product lens
Started from repetitive user pain inside the engineering workflow, defined the useful output, automated the highest-friction steps, and made deviations easy to inspect.
Outcome: Replaced a tedious manual device-to-report process with an automated validation pipeline.
SAMSUNG · ON-DEVICE AI

AI GIF Event Detection

LRCN · TFLite · Dataset creation · Android integration
Problem
Create game highlights by detecting meaningful events such as kills, level completion or match outcomes and preserving the relevant moments as GIFs.
Approach

SNAPAI · PRODUCT DISCOVERY

From Smart Capture to Marketplace

PRD · User discovery · Market research · MVP · GTM validation
Problem
At small events, trips and everyday moments, someone often stays behind the camera; professional photography can feel expensive or cumbersome for short, spontaneous needs.
V1
Started with an unattended AI Smart Capture concept: place a phone on a stand and automatically capture important event moments, then curate/edit the album.
Discovery
User conversations surfaced a core limitation: real events move. Occlusion, changing angles and unpredictable moments make fixed unattended capture unreliable.
Pivot
Reframed SnapAI as an on-demand capture marketplace: a human captures the moment while AI supports quality, culling, editing, curation and delivery.
Current work: PRD, customer/photographer conversations, competitor research, pricing and supply economics, MVP flow and market validation. Early culling/editing workflow tested on ~120 photos.
SAMSUNG · AI PRODUCTIVITY

AI Tools for Developer Workflows

AI CL Analyzer · Delta Merge Tool · Developer experience
Problem
Understanding code changes and wiki context can be slow; build failures can create repeated waiting; Android-version code migration also requires repetitive verification.
Approach
Contributed to an AI CL Analyzer concept for change/wiki summarization and build checking. Built a Delta Merge Tool to automate verification of model-specific code across Android-version paths.
Product lens
Focused on developer time as the user pain: reduce repetitive reading, checking and verification while keeping engineers in control of final review.
Theme: AI is most useful when tied to a concrete workflow, measurable friction and a clear human decision point.
